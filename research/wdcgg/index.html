WDCGG Data Pipeline

What has to happen before a long-term atmospheric record can support an environmental conclusion?

Source repository ↗

Focus

Data provenance
Quality control
Reproducibility

Start with the source.

This Python research pipeline screens, harmonises and analyses WDCGG CO₂ and CH₄ observations. It ties each archive to a frozen manifest using SHA-256, aligns UTC timestamps and units, and retains contributor-valid observations before calculating monthly means.

The study screened 362 station–gas catalogue products and acquired 38 official datasets spanning 23 physical stations. The primary Core cohort comprises 26 station–gas products at 14 stations. A product is a station–gas series, not an independent station.

What the result supports.

The frozen Core summaries report same-month Seasonal Sen trends of 2.5113 ppm yr⁻¹ for CO₂ and 11.3146 ppb yr⁻¹ for CH₄. These describe a selected, non-random cohort. They are not global atmospheric averages.

Primary environmental findings use observed-only records. Statistical anomaly flags are review annotations, not automatic deletion. Gap-reconstruction benchmarks do not justify filling every missing observation.

Methods and reproducibility

Core qualification uses 75% within-month and 75% station-period coverage; Extended uses 75% / 60%. A 20-cell sensitivity grid recomputes qualification independently.

Validation includes physical-station-held-out anomaly detection and repeated gap reconstruction. Trend uncertainty uses a run-aware residual moving-block bootstrap, with a 12-month primary block and 6/24-month sensitivity checks.

Offline tests run on synthetic fixtures. A full rerun requires the 38 source archives under provider terms, substantial compute, and the documented source layout.

Reproduction guide ↗

Status and limits

The associated DSIT 2026 manuscript remains under peer-review revision. No acceptance, DOI or proceedings publication is claimed. Raw third-party observations are not redistributed. This portfolio describes the public software and frozen outputs; it does not claim an independent full-study rerun.

Software as part of the evidence.

The public repository contains executable modules, configuration, offline tests, source manifests and compact frozen results. Its contribution is a traceable path between acquired records, methodological decisions and final summaries.
