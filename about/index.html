About

A habit of
looking closer.

I’m Han Che, an undergraduate in Data Science and Big Data Technology at Xi’an Jiaotong-Liverpool University.

Questions, code, context.

I’m interested in machine learning, data science, reproducible research, research software engineering and computational methods. My public work includes atmospheric data pipelines, ozone prediction, language-model tool selection and relational database design.

I care about the path to a result: source records, evaluation choices, and the assumptions that remain after the code runs. I want the software to make those decisions easier to inspect.

Technical practice

Python, SQL/PostgreSQL, pandas, NumPy, scikit-learn, PyTorch and Git feature in my public projects. The research pages link to code and documented limitations so the evidence can speak for itself.

Ways of seeing

Photography and visual storytelling are personal interests. This site makes space for that work without substituting stock imagery or invented photographs.

What I’m curious about

How can environmental models remain useful outside their fitting conditions? What does reproducibility require when the original data cannot be redistributed? How can a visual explanation make an uncertainty easier to understand?
